# Responsive Timeline Detail Design

## Goal

ให้ข้อมูลรายละเอียด Timeline บนหน้าจอมือถือยังคงโครงสร้างแบบ Desktop เป็นตาราง 4 คอลัมน์ โดยไม่ต้องเลื่อนซ้าย–ขวา

## Design

- แสดงหัวตารางบนทุกขนาดหน้าจอ
- ใช้ 4 คอลัมน์เสมอ: ลำดับ, ขั้นตอน, วันที่กำหนด, จัดการ
- บนมือถือใช้คอลัมน์แบบยืดหยุ่นและลดขนาดเฉพาะส่วนที่จำเป็น
- อนุญาตให้ชื่อขั้นตอน คำอธิบาย และวันที่ตัดบรรทัดได้
- ปุ่ม “แก้วันที่” ยังคงอยู่ในคอลัมน์จัดการและกดได้ง่าย
- Desktop ตั้งแต่ breakpoint `lg` ใช้ขนาดคอลัมน์เดิม
- ไม่เปลี่ยน logic การคำนวณวันที่ การแก้ไขข้อมูล หรือ print layout

## Verification

- เพิ่ม component test ยืนยันหัวตารางไม่ถูกซ่อนบนมือถือ
- เพิ่ม component test ยืนยันแถว Timeline ใช้ responsive 4-column grid
- รัน test file, typecheck, lint และตรวจหน้า local ด้วย browser
